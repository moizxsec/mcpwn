Templates are **nuclei-style rule-packs**: the same tamper-rule array a `-r`
file carries, plus an `id` and an `info` metadata block describing the attack it
encodes. Load one into any run with `--template <id>`, or list and lint them:

```bash
mcpwn templates list
mcpwn templates show tool-poisoning
mcpwn templates lint
```

Each card below is generated at build time from
[`templates/*.json`](https://github.com/moizxsec/mcpwn/tree/main/templates) — drop
a new pack in that directory and it appears here automatically. For the attack
class each one encodes (and its remediation), see the
[threat taxonomy](/mcpwn/threats/).
